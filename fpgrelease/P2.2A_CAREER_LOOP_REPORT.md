# P2.2-A — Career Loop

Implemented a meaningful daily-action loop for the career hub.

## Changes
- One meaningful career action can be consumed per simulation day.
- Training consumes the day's career action.
- A second training attempt on the same day is rejected.
- Training is blocked when a career fixture is scheduled for today; the match takes priority.
- Completing the player's match marks the day as a match action.
- Advancing the simulation day clears the action lock for the new day.
- The action state is persisted in `careerMatchSnapshot`, so SAVE/LOAD cannot silently reset it.
- Career Home now exposes a visible `DZISIAJ` action-state card and disables training after the daily action is consumed.

## Intended loop
`day -> one career action -> continue day -> recovery/world -> next day`

The next P2.2 stage should build the richer match presentation on top of this loop.

Flutter SDK was not available in the audit environment, so no claim is made that `flutter test` was executed here.
