# FPG V25.1 — SAVE/LOAD WORLD INTEGRATION PASS

## Cel
Połączyć persistence z integralnością świata i transakcją meczu kariery.

## Zmiany
- `careerMatchSnapshot` zapisuje teraz jednoznaczny `fixtureKey`.
- LOAD odrzuca zapis świata, jeśli przywrócone kluby/zawodnicy łamią `WorldIntegrityValidator`.
- LOAD odrzuca oczekującą transakcję meczu, jeśli nie istnieje odpowiadający jej fixture.
- Jeśli fixture jest już oznaczony jako rozegrany, jego wynik musi dokładnie odpowiadać wynikowi transakcji zapisanej w snapshot.
- Dodano regresje dla identyfikacji fixture i czystej granicy persistence po finalizacji meczu.

## Dlaczego
Save wykonany pomiędzy `reconcileInteractiveFixtureResult()` a `finalizeCareerMatchDay()` jest legalnym stanem przejściowym. Po restarcie aplikacja musi wiedzieć dokładnie, którego fixture dotyczy niedokończona transakcja i nie może zastosować jej do innego meczu.
