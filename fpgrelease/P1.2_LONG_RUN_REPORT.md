# FPG P1.2 — Long-Run World Audit

## Cel
Dodać bezpieczny, powtarzalny audyt świata dla symulacji wielosezonowych.

## Zmiany
- `WorldLongRunAuditSnapshot` zbiera metryki świata po każdym sezonie.
- `WorldLongRunAudit` wykorzystuje istniejący `WorldIntegrityValidator` i nie naprawia danych automatycznie.
- Dodano regresję pięciu kolejnych przejść sezonowych na deterministycznym świecie testowym.
- Każdy przebieg sprawdza: liczbę klubów, liczbę zawodników, minimalną kadrę seniorów, duplikaty ID oraz zawodników z nieznanym klubem.
- Audyt jest gotowy do wykorzystania również przez przyszły raport CLI/CI.

## Ważne ograniczenie
W środowisku przygotowania ZIP nie ma Flutter SDK, więc test nie został uruchomiony tutaj przez `flutter test`. Plik testowy jest gotowy do uruchomienia w CI/GitHub Actions.
