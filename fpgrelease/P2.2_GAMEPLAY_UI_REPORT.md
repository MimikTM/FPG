# FPG P2.2 — Gameplay Hub / UX

## Cel
Przejście z samej stabilizacji silnika do użytecznego huba kariery.

## Zmiany
- Career Home pokazuje prawdziwy najbliższy fixture zawodnika.
- Przycisk meczu jest aktywny tylko wtedy, gdy mecz rzeczywiście odbywa się dzisiaj.
- Dodano akcję `Kontynuuj dzień`, która przesuwa kalendarz dokładnie o jeden dzień.
- Dodano w GameEngine `nextCareerFixture` i `careerHasMatchToday`.
- Dodano test regresyjny huba.

## Cel UX
Gracz ma teraz czytelny przepływ: sprawdź najbliższy mecz → trening/decyzje → kontynuuj dzień → mecz w dniu meczu.

## Flutter
W środowisku roboczym nadal nie ma Flutter/Dart SDK, więc `flutter test` i `flutter build apk` nie zostały uruchomione lokalnie.
