# FPG V25.1 — Match Transaction Finalization Pass

## Cel
Utwardzić zapis bezpośrednio po interaktywnym meczu i uniemożliwić podwójne wykonanie finalizacji po przypadkowym drugim wywołaniu.

## Zmiana
`GameEngine.finalizeCareerMatchDay()` po pełnym wykonaniu:
- konsekwencji kariery,
- pozostałych meczów,
- world tick,
- synchronizacji career/world,
- ewentualnego rolloveru sezonu,

czyści transient `careerMatchSnapshot`.

## Dlaczego
Przed zmianą zapis wykonany natychmiast po zakończeniu meczu mógł zachować `_careerMatchToday == true`, mimo że konsekwencje dnia zostały już zastosowane. Po LOAD stan wyglądał jak aktywna transakcja mimo jej zakończenia.

Dodatkowo ponowne wywołanie `finalizeCareerMatchDay()` mogło ponownie wykonać część post-match/world flow.

## Oczekiwany stan
`reconcileInteractiveFixtureResult()` → snapshot aktywny.

`finalizeCareerMatchDay()` → snapshot wyczyszczony.

Kolejne `finalizeCareerMatchDay()` → `StateError`.
