# FPG V25.1 — Technical RC: Save/Load release gate

## Scope
This pass closes the remaining persistence-side release risks without adding gameplay systems.

## Changes
- Added a real **Load Career** action to the home screen.
- `GameEngine.loadWorld()` now preflights the scalar game state and career player before mutating the live engine.
- Career-player references are checked against the candidate world (club and contract ownership).
- A save with `careerPlayer: null` now explicitly clears any career already held by the running engine instead of accidentally retaining it.
- Existing world, fixture, pending-match and roster validation remains part of the same preflight boundary.

## Release gate
The next verification is runtime-only:
1. Save career.
2. Force-close app.
3. Reopen.
4. Load career.
5. Confirm date, club, player, fixture and table are identical.
6. Repeat with an unplayed match today.
7. Repeat on 30 June / 1 July.

Flutter/Dart SDK is not present in this environment, so `flutter analyze`, `flutter test` and a release build cannot be truthfully claimed here.
