# FPG P1.8 — Match Rating & Minutes Hardening

## Zakres
- centralny `CareerMatchRatingEngine` dla oceny meczu zawodnika kariery;
- rating uwzględnia wynik, pozycję, minuty, formę, fitness, gole i asysty;
- rating jest zawsze ograniczony do 4.0–10.0;
- 0 minut nie tworzy występu ani ratingu;
- starter dostaje 90 minut lub realistyczny zakres 60–89;
- rezerwowy dostaje 10–35 minut, a wejście jest spójne z czasem gry;
- statystyki indywidualne (strzały, celne, key passes, dryblingi, kartki) są naliczane proporcjonalnie do minut i pozycji;
- dodano idempotency guard dla przetwarzania statystyk kariery per fixture;
- guard jest zapisywany w snapshotcie kariery i przywracany po LOAD;
- `WorldSave` schema podniesiono z 11 do 12.

Zostały dodane testy regresyjne gotowe do wykonania w GitHub Actions lub lokalnym Flutter SDK.
