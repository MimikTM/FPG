# FPG V25.1 — Long-Run Stability Pass

## Cel
Zweryfikować główną pętlę kariery po naprawie transakcji meczu i SAVE/LOAD:

`dzień -> mecz/interaktywny commit -> świat -> kolejny dzień`

## Dodany test
`test/career_long_run_stability_test.dart`

Test wykonuje 400 kolejnych dni kariery i kontroluje:
- zatrzymanie kalendarza na dniu meczu kariery,
- obecność właściwego fixture w aktualnym dniu,
- pojedynczy commit wyniku interaktywnego,
- idempotencję ponownego commitowania tego samego wyniku,
- brak nierozgranych meczów kariery pozostawionych w przeszłości,
- integralność tabeli po każdym dniu,
- przejście co najmniej do kolejnego roku/sezonu,
- obecność zarówno meczów interaktywnych, jak i autonomicznych.

## Ważne
W środowisku roboczym nie ma Flutter/Dart SDK, dlatego test nie został uruchomiony lokalnie. Został dodany jako test regresyjny do wykonania przez CI/środowisko z Flutter SDK.
