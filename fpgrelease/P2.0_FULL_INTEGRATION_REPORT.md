# FPG P2.0 — Full Integration / Match Transaction

## Cel
Zamknięcie najważniejszego rozjazdu między automatyczną symulacją ligi a interaktywnym ekranem meczu.

## Zmiana
Interaktywny mecz nie wywołuje już `playFixture()` przy wejściu na ekran. Zamiast tego:

1. `previewFixture()` generuje oficjalny wynik referencyjny bez zmiany stanu.
2. Match2D używa tego wyniku jako celu/prezentacji.
3. Po zakończeniu meczu `reconcileInteractiveFixtureResult()` zatwierdza finalny wynik.
4. Dopiero wtedy fixture zostaje `played`, tabela dostaje wynik, a statystyki kariery są naliczane.

## Gwarancje
- rozpoczęcie interaktywnego meczu nie zwiększa tabeli;
- przerwanie przed końcem nie zapisuje fikcyjnego wyniku jako rozegranego meczu;
- finalny wynik z boiska jest wynikiem transakcji;
- ten sam commit nie może drugi raz nabić tabeli/statystyk;
- po commitcie `validateLeagueIntegrity()` musi pozostać prawdziwe.

## Test
`test/p2_full_integration_transaction_test.dart` pokrywa preview → commit → drugi commit.

## Flutter
W tym środowisku nie ma Flutter SDK, więc test nie został tutaj uruchomiony przez `flutter test`. Zmiana została sprawdzona statycznie i ZIP został zweryfikowany integralnościowo.
