# P1.3 — Long-Term Balance Hardening

## Changes

- Development now enforces `Player.potential` as the OVR ceiling.
- Long-run audit tracks average/min/max OVR, elite-player count and potential breaches.
- World integrity audit now fails on potential breaches or invalid OVR range.
- Five-season lifecycle regression was extended to ten seasons.
- Added a deterministic development regression test.

## Reason

The development model can change several attributes at once. Without a final OVR ceiling, a small remaining potential gap could be exceeded by an attribute-weighted OVR recalculation. Over many seasons this could distort the world distribution.

Static source checks completed. Flutter/Dart execution is still pending because this audit environment does not contain the Flutter SDK.
