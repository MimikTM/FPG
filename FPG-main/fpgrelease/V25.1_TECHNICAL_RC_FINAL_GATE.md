# FPG V25.1 — Technical RC Final Gate

This pass closes the remaining application-side integrity gap around the interactive match commit.

## Added

- Interactive fixture reconciliation now rejects negative or implausibly large scores.
- A `MatchScreen` can only commit a fixture belonging to the active career player's club and the current in-game calendar day.
- The validation runs before any fixture/table mutation.
- Added a regression test proving an invalid score leaves the fixture untouched.

## Release gate

The project should now move from engine hardening to device/CI verification. Do not add new gameplay systems until these checks pass on the actual APK:

1. Save → force close → Load.
2. Load on a match day → Match 2D → finish → return to career.
3. Save immediately after the match → restart → Load.
4. Save on/around 30 June → restart → Load → continue into 1 July.
5. Transfer + loan → Save → restart → Load → continue.
6. Run `flutter analyze`, `flutter test`, `flutter build apk --release` and `flutter build appbundle --release` in CI.

If these pass, the project enters **Beta Polish / Release Candidate**. No further engine expansion is required for Open Beta.
