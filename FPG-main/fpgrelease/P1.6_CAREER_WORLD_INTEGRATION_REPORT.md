# P1.6 — Career ↔ World integration hardening

## Zmiana
CareerWorldBridge wcześniej przekazywał z PlayerCareer do świata część stanu, ale po ticku świata nie kopiował z powrotem kluczowych danych piłkarskich: wieku, OVR, potencjału i atrybutów. Rozwój świata mógł więc zostać utracony w warstwie kariery.

## Naprawa
- synchronizacja wieku, OVR, potencjału i sześciu atrybutów;
- synchronizacja fitness/form/fatigue;
- synchronizacja czasu kontraktu, pensji, statusu i wartości rynkowej;
- validator `CareerWorldIntegrityValidator` do wykrywania rozjazdu;
- regresja testująca tożsamość i stan projekcji.

## Testy
Pełne `flutter test` nadal wymagają prawdziwego Flutter SDK. Test jest dodany do repozytorium i powinien zostać uruchomiony w GitHub Actions.
