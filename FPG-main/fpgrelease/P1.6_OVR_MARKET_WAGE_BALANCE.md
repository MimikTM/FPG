# FPG V25.1 — OVR / Market Value / Wage Balance Pass

## Why this pass exists

The development engine previously recalculated `weeklyWage` directly from OVR every time it refreshed a player's market value. That made wage a hidden side effect of attribute development and could overwrite a negotiated contractual salary.

The project already has a dedicated `MarketValueEngine`, so valuation and contract salary should be separate domains.

## Changes

- `DevelopmentEngine` now delegates world-player valuation to `MarketValueEngine`.
- Development no longer rewrites `weeklyWage` from OVR.
- Contractual wage remains stable until a contract/negotiation system changes it.
- Added regression tests for wage preservation and deterministic market valuation.

## Result

The intended relationship is now:

`OVR / age / potential / performance -> market value`

while:

`contract negotiation -> weekly wage`

A player's development can increase market value without silently changing the signed salary.
