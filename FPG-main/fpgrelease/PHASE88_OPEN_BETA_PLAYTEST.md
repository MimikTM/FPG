# Phase 88 — Open Beta / Playtest

Status: **PLAYTEST PACKAGE READY**

## Objective
Validate fun, clarity, progression and stability with real players rather than only code-level checks.

## First-session script
1. New install.
2. Complete or skip tutorial.
3. Create a player.
4. Select a club.
5. Complete training.
6. Play one full 2D match.
7. Inspect result, table and career stats.
8. Save, restart and load.
9. Continue to the next match.
10. Make at least one transfer/contract/relationship decision when available.

## Feedback to collect
- Where did the player hesitate?
- Which screen was unclear?
- Did the match feel responsive?
- Did the result feel earned by gameplay?
- Was progression understandable?
- Which system was most/least interesting?
- Any crash, freeze, duplicate result or lost save?

## Severity
- P0: crash, corrupted/lost save, impossible progression
- P1: match/result integrity error, blocked career progression
- P2: major UX confusion, broken audio/presentation
- P3: polish, wording, cosmetic issue

## Exit criterion
No open P0/P1 issues and the core loop is understandable without developer assistance.
