# FPG V25.1 — Runtime Seed Isolation Pass

## Znaleziony problem
`GameEngine` trzymał bezpośrednie referencje do mutowalnych obiektów `WorldData.clubs` i `WorldData.leagues`. Oznaczało to, że jedna instancja kariery mogła zmienić dane startowe kolejnej kariery. Ten sam problem mógł powodować test-order dependency.

## Naprawa
- `League` jest teraz kopiowana do nowego obiektu dla każdej instancji `GameEngine`.
- `Club` jest kopiowany przez `toJson()/fromJson()`.
- `Player` jest kopiowany przez `toJson()/fromJson()`.
- `WorldData` pozostaje wyłącznie seedem; runtime nie mutuje jego obiektów.

## Regresje
Dodano `test/game_engine_seed_isolation_test.dart` sprawdzający:
- niezależność klubów, zawodników i lig pomiędzy dwiema karierami,
- brak przecieku budżetu/menedżera/wieku,
- brak przecieku `leagueId`, `clubId` i `squadStatus`.

## Weryfikacja
Flutter/Dart SDK nie jest dostępny w tym środowisku, więc `flutter analyze` i `flutter test` nie zostały uruchomione lokalnie.
