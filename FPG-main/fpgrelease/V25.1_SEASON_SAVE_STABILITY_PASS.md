# FPG V25.1 — Season & Save Stability Pass

## Implemented

### 1. Season rollover off-by-one fix
`GameEngine._advanceSeason()` is executed on June 30, before `GameState.nextDay()` changes the calendar to July 1. The next campaign must therefore be generated from `state.year + 1`.

The previous implementation generated the next fixture list with `state.season`, which could leave a new-season schedule stamped with the completed campaign year. This pass uses one explicit `nextSeasonStartYear` for both `WorldEngine.processEndOfSeason()` and `FixtureGenerator.generateSeasonFixtures()`.

### 2. Regression coverage
Added `test/season_transition_game_engine_regression_test.dart` covering:
- end-of-season processing on June 30,
- July 1 calendar rollover,
- season increment,
- new fixtures belonging only to the new campaign,
- clean league standings after regeneration,
- league/fixture integrity after the transition.
