# P2.2-D — Season Gameplay

Implemented a season overview as a read-only gameplay layer over the authoritative league table.

## Included
- Current league position and record.
- Season progress and remaining league matches.
- Board objective derived from club strength.
- Objective status (currently met / not met).
- New Season screen linked from Career hub.
- Regression test for season overview derivation.

No second standings source was introduced; the UI reads `LeagueEngine.table`.
